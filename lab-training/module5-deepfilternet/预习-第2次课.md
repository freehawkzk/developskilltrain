## 前置要求

本次课是代码实战课，需要完成以下准备：

### 1. DeepFilterNet论文回顾（约15分钟）

确保你已经理解上节课的核心概念：
- 两阶段架构：Enhancement（ERB掩码）+ Deep Filtering（时域滤波）
- ERB频带的含义和作用
- alpha参数的含义（控制DF阶段的混合比例）

如果论文阅读引导卡中的问题还有未完成的，请先补上。

### 2. 代码预浏览（约30分钟）

打开 `DeepFilterNet-main/DeepFilterNet/df/` 目录，快速浏览以下文件（不需要读懂每一行）：

| 文件 | 浏览重点 |
|------|---------|
| `config.py` | 找到 `DfParams` 类，注意默认参数值（SR、FFT_SIZE、NB_ERB等） |
| `deepfilternet.py` | 找到 `DfNet` 类的 `forward()` 方法，理解数据流 |
| `modules.py` | 浏览类名列表（Conv2dNormAct、GroupedGRU、Mask、DfOp等） |
| `enhance.py` | 找到 `init_df()` 和 `enhance()` 函数签名 |

浏览策略：先看类和函数的名字、参数列表、docstring，暂时跳过具体实现。

### 3. 环境安装（约15分钟）

请课前完成DeepFilterNet的环境准备：

**Python 代码用 vendored 源码**——notebook 通过 `sys.path.insert(0, '../DeepFilterNet-main/DeepFilterNet')` 直接引用 `DeepFilterNet-main/DeepFilterNet/df/`（与作者仓库一致）。

**但仍需安装 `deepfilterlib`**（提供 `libdf` Rust 扩展）：
```bash
pip install deepfilterlib
```
vendored 的 `df/` 是 Python 源码，但 `df.enhance.init_df()` 和 `enhance()` 调用底层 STFT/ERB/DfOp 时需要 `libdf`（Rust 编译扩展）。`deepfilterlib` PyPI 包为各平台提供预编译 wheel，无需 Rust 工具链。

**还需准备预训练权重**：
```bash
cd DeepFilterNet-main/models/
unzip DeepFilterNet3.zip
```
确认解压后能看到 `DeepFilterNet3/` 目录。

> **关于容易混淆的几个包**：
> - `deepfilterlib` (PyPI): **必需**，提供 `libdf` Rust 扩展（STFT/ERB/DF 算子）
> - `deep-filter` (PyPI): DeepFilterNet 作者的 Rust 命令行工具，不是 Python 包，不适合教学
> - `deepfilternet` (PyPI): 旧 Python 打包版本，与 vendored 源码有 API 差异——本课程**不装它**，避免和 vendored 源码冲突

### 4. 预训练模型解压（约5分钟）

```bash
cd DeepFilterNet-main/models/
unzip DeepFilterNet3.zip
```

确认解压后能看到 `DeepFilterNet3/` 目录。
